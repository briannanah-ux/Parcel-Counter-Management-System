# Changelog

All notable changes to this project are documented in this file.

The format follows the principles of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning.

## [1.0.0] - 2026-07-21

### Added

- Arduino Mega firmware for locker control, fingerprint interaction, user prompts and status handling
- ESP8266 firmware for Wi-Fi and Firebase communication
- Supporting Arduino configuration and helper files
- Hardware pinout documentation
- Bill of materials
- System overview and architecture documentation
- Hardware and firmware design documentation
- Cloud and dashboard design documentation
- Testing and validation notes
- Design decisions, limitations, future improvements and lessons learned
- System architecture and customer journey diagrams
- Repository README, MIT licence and Git ignore configuration

### Notes

- This release is a portfolio refresh of the original final-year engineering prototype.
- The repository documents the intended cloud monitoring workflow, but a production-ready web dashboard is not included in this release.
- Wi-Fi credentials and Firebase secrets are intentionally excluded from version control.
